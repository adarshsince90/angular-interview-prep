# Single Page Application (SPA)

## Definition

A Single Page Application loads once and dynamically updates the UI without performing full page reloads.

## Traditional Website Flow

Browser
→ Request Page
→ Server Generates HTML
→ Full Page Reload

## SPA Flow

Browser
→ Load Application Once
→ JavaScript Controls Navigation
→ UI Updates Dynamically

## Advantages

- Faster user experience
- No full page refresh
- Rich interactions
- Better frontend/backend separation

## Challenges

- Larger initial bundle size
- SEO considerations
- More frontend complexity
- JavaScript dependency

## Why Angular Fits SPAs

- Components
- Routing
- Services
- Dependency Injection
- HttpClient
- State Management

## Common Interview Questions

- What is an SPA?
- SPA vs MPA?
- Why are SPAs popular?
- What are SPA disadvantages?
- How does Angular support SPA development?

## Key Message

Angular is a framework designed to build maintainable Single Page Applications that provide a rich user experience while keeping frontend and backend concerns separate.
